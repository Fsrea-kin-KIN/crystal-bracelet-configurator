# 手串定制工具

面向线上定制商家的轻量手串设计工具。商家在后台维护自己的珠材、图片和价格，将顾客页面链接发给顾客；顾客完成搭配后生成可继续打开的方案，商家在后台查看并处理。

## 产品流程

1. 商家进入后台设置店铺名称、联系方式、制作时间、发货说明、定制须知和手工费。
2. 商家新增珠材，选择色系、能量需求与五行归属，分别维护 6 / 8 / 10 mm 的售价、库存和在售状态，并上传自己的商品图片。
3. 顾客首页提供三个独立入口：自由搭配、帮我推荐、从灵感开始。
4. “帮我推荐”根据顾客选择的能量状态或五行方向展示对应实物珠材；“从灵感开始”展示商家上传的成品图、说明和实际用料，可一键套用后继续修改。
5. 顾客可以先保存或分享方案；只有填写称呼、联系方式并确认提交后，方案才会进入商家后台。
6. 商家在后台查看顾客信息、用料、报价状态、备注和参考图片，并更新处理状态。

## 已有功能

- 任意珠位新增、替换、删除、复制、拖动和交换
- 手围、珠径、配件、绳色与备注配置
- 根据手围和珠径计算珠位容量，不擅自补充或删除珠子
- 商家新增珠材、上传多张图片、填写说明，并分别设置 6 / 8 / 10 mm 的价格、库存和在售状态
- 上传商品图时自动去除纯色背景、柔化边缘并居中生成 720 x 720 透明 PNG，可随时改用原图
- 顾客查看珠材实物图、说明和不同珠径规格
- 三个独立顾客页面：首页选择入口、自由搭配编辑器、推荐选材页和成品灵感页
- 帮我推荐：按当下想要的状态或偏好的五行筛选实物珠材，并带入自由搭配
- 从灵感开始：展示商家成品实拍、材料和规格，并套用实际配方继续修改
- 商家可为珠材和推荐成品维护能量、五行标签；五行固定为金、木、水、火、土，能量需求可自定义
- 商家可自行修改推荐页的能量提问、五行提问和各项推荐选项；内置文字仅作为初始示例
- 珠材与配件图片追加、替换和删除，配件与绳色自行新增
- 商家可新增吊坠、隔片、佛头等配件分类，并为商品调整所属分类
- 商品上下架、店铺名称和 6/8/10 mm 手工费维护
- 未完成手串可保存为灵感方案，不显示误导性的最终报价
- 顾客草稿自动保存、历史搭配、方案持久化和分享链接
- 保存/分享与提交商家分开，未提交的私人方案不会进入商家后台
- 商家查看顾客称呼、联系方式、数量，搜索、筛选方案并更新处理状态
- 保存或提交方案不会自动扣减库存；提交时会重新检查当前在售状态和库存
- 手机与电脑响应式界面
- SQLite 本地数据存储与自动测试
- 商家后台首次设置密码、登录、退出和修改密码

## 空白商家版

新建数据库时默认不预置任何珠材或珠子图片。商家从后台上传自己的商品后，珠材会自动出现在顾客页面对应色系中。

配件和绳色保留一组可编辑的基础选项，以便首次启动后可以直接配置。仓库忽略运行数据库、商家上传图片、演示原图和竞品参考图，避免把商家数据提交到 GitHub。

## 商品图片处理

后台新增或更换珠材、配件和绳色图片时，会先显示原图与处理后效果。系统只从图片边缘识别并移除连通的纯色背景，尽量保留白水晶等浅色商品内部的纹理；背景较复杂或识别不可靠时会默认保留原图，不会强行抠图。商家确认预览后再保存，不需要额外安装图片处理软件或付费 Agent。

自定义分类中的商品统一沿用配件规则：每个商品占用一个珠位、按件计价、受库存和上下架状态约束，并允许重复添加。默认“配件”分类可以改名但不能删除；其他分类只有在不包含商品时才能删除，避免误删商品。

## 本地运行

需要 Node.js 24 或更高版本。

不要直接双击 HTML 文件。顾客页面和商家后台都需要先启动本地服务，否则浏览器无法访问接口和商品数据。

在文件夹中双击对应脚本即可：

- `开始使用.cmd`（第一次使用建议从这里开始）
- `打开顾客页面.cmd`
- `打开商家后台.cmd`

重复双击不会反复启动多个服务；脚本会复用已经运行的本地服务。

```powershell
npm start
```

打开：

- 顾客入口页：`http://127.0.0.1:4181/`
- 自由搭配：`http://127.0.0.1:4181/diy.html`
- 帮我推荐：`http://127.0.0.1:4181/recommend.html`
- 从灵感开始：`http://127.0.0.1:4181/inspiration.html`
- 商家管理后台：`http://127.0.0.1:4181/admin.html`

第一次打开商家后台时需要设置至少 8 个字符的密码。勾选“保持登录 30 天”后，关闭浏览器或重启本地工具仍可直接进入后台。密码只保存为加密摘要，不会包含在“店铺设置 → 备份与恢复”导出的业务备份中。

忘记后台密码时，在工具文件夹中双击 `重置商家后台密码.cmd`，输入两次新密码即可。重置后原有登录状态会全部退出，但商品、图片、方案和业务备份不会受到影响。

首次运行会在 `data/` 下创建数据库。商家上传的图片保存在 `data/uploads/`，部署和迁移时需要同时备份数据库与该目录。

运行自动测试：

```powershell
npm test
```

## 商业交付边界

当前版本适合本地演示和单商家独立部署。它不是支付或订单系统，不收款、不处理物流，也不会自动扣减库存。正式连接公网前还需要配置 HTTPS、域名、定期备份和服务器运行环境。
